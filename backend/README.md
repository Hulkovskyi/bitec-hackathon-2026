# Серверна частина

Початкова тека для серверної логіки командного рішення.

Після узгодження структури й перенесення прийнятого коду з чернетки потрібно додати залежності, опис API та перевірені команди запуску. У чернетці API використовує Node.js 24, Express і SQLite. Приклади змінних середовища зберігати без справжніх паролів і ключів.
