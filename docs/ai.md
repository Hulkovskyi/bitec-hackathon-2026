# Як ми використали ШІ

## Інструменти й робота

Команда використала ChatGPT і Codex (OpenAI) для обговорення концепції, планування етапів, звіряння з умовами хакатону й підготовки контрактів та документації. Codex допомагав з реалізацією реєстру, переглядом коду та відтворенням локальних сценаріїв. У рев’ю перевірили, як інтерфейс обробляє запізнілу відповідь після зміни розділу, сторінки чи переходу до створення заходу. [Запис перевірки](stages/01-registry.md)

## Рішення команди

Учасник команди обрав концепцію моніторингу антикорупційної програми з доступом за ролями, журналом дій та погодженням результату людиною. Для демонстрації використовуємо синтетичні дані. У публічному PR запропоновано назву Digital Anti-Corruption Monitor, яку показує застосунок. Список відхилених альтернатив із власними аргументами та принципи продукту команда доповнить перед поданням.

## Перевірка

`StaS228-M` виконав рев’ю через Codex. Результати спираються на перевірку конкретного коміту, 10 автоматичних тестів, збірку й відтворення сценаріїв у Chrome. Після приймання у приватній чернетці код перенесено на публічне рев’ю, де запуск повторено з чистою локальною БД. [Поточний стан](PROGRESS.md)

Операції реєстру працюють локально без моделі або зовнішнього ШІ-сервісу. Для майбутніх висновків із наслідками команда планує вказувати явні правила, вихідні дані або підтвердження відповідальної особи. [Політика використання ШІ](https://hack.bitec.com.ua/polityka-shi/)
