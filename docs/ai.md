# Як ми використали ШІ

## Інструменти й робота

Команда використала ChatGPT і Codex (OpenAI) для обговорення концепції, планування етапів, звіряння з умовами хакатону й підготовки контрактів та документації. Codex допомагав з реалізацією реєстру й погодження, переглядом коду та відтворенням локальних сценаріїв. У рев’ю перевірили доступ за періодом, версії доказів, аудит і поведінку інтерфейсу під час запізнілої відповіді. [Запис етапу 1](stages/01-registry.md) · [Запис етапу 2](stages/02-workflow.md)

## Рішення команди

Учасник команди обрав концепцію моніторингу антикорупційної програми з доступом за ролями, журналом дій та погодженням результату людиною. Для демонстрації використовуємо синтетичні дані. Публічний репозиторій використовує назву Digital Anti-Corruption Monitor, яку показує застосунок. Список відхилених альтернатив із власними аргументами та принципи продукту команда доповнить перед поданням.

## Перевірка

`StaS228-M` виконав рев’ю через Codex. Для етапу 2 перевірено зафіксований коміт, 21 автоматичний тест, збірку та сценарії в браузері на ізольованій SQLite-базі. Перенесення проходить окреме публічне рев’ю. [Поточний стан](PROGRESS.md)

Операції реєстру й погодження працюють локально без моделі або зовнішнього ШІ-сервісу. Для майбутніх висновків із наслідками команда планує вказувати явні правила, вихідні дані або підтвердження відповідальної особи. [Політика використання ШІ](https://hack.bitec.com.ua/polityka-shi/)
