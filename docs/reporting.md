# Піврічний звіт і аналітична довідка

У кабінеті координатора, керівника, аналітика й адміністратора відкрийте **Звіти** та виберіть H1 або H2. Виконавець працює зі своїми заходами й отримує `403` на запит звіту програми.

Звіт охоплює три розділи програми. У кожному рядку є захід і підрозділ, фактичний строк, стан та результат або причина невиконання. Для постійного заходу з погодженим результатом фактичний строк — 30.06 або 31.12 відповідного року. Для майбутнього строку за відсутності погодження показано «Строк виконання не настав».

## Вибірка й формати

- Спільна вибірка обмежена програмою та доступними підрозділами до формування підсумків. Дата зрізу — менша з поточної київської дати й кінця півріччя. Пізнє погодження враховується за датою результату.
- Сервер читає погоджені результати й історичні поля у спільній транзакції зчитування. Новіша чернетка не замінює погоджену ревізію. Для постійного заходу вибирається лише точне півріччя.
- Екран, аналітична довідка, друкована розмітка та завантаження CSV використовують той самий JSON. Окремий запит CSV читає актуальний знімок за тими самими правилами.
- Частка повного виконання — кількість виконаних заходів, поділена на кількість рядків. За нульового знаменника довідка показує «Немає даних». Заходи з недосягнутою ціллю відкривають джерельну ревізію.

`GET /api/reports/half-year?programId=…&year=2026&half=2` повертає JSON. Додайте `format=csv` для CSV з UTF‑8 BOM. Текстові поля, які таблиця могла б сприйняти як формулу, екрануються. [Контракт](workflow-contract.md#піврічний-звіт-і-аналітична-довідка)
