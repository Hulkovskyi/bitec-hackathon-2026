# Піврічний звіт і аналітична довідка

Запустіть локальне демо за [README](../README.md#як-запустити). Увійдіть як «Координатор А», відкрийте **Звіти** та виберіть І або ІІ півріччя. Екран відображає три розділи програми, фактичний строк виконання, стан та опис результату або причину невиконання. **Друкувати** відкриває форму A4. **Завантажити CSV** експортує рядки з відкритого звіту.

Координатор, керівник та аналітик бачать лише дозволені підрозділи вибраної програми. Адміністратор бачить усі підрозділи програми. З обліковки виконавця API звіту відповідає `403`.

## Вибірка і формати

Запит `GET /api/reports/half-year?programId=…&year=2026&half=2&format=json` повертає програму, період, момент формування, межі доступу, три розділи й підсумки. Параметр `format=csv` повертає CSV з UTF‑8 BOM. Кожен запит читає послідовний знімок на SQLite або PostgreSQL. Екран, друк, CSV із браузера та довідка використовують один завантажений знімок, а окремий запит API формує новий.

Пізно погоджені результати відносяться до дати результату. Одноразовий захід, достроково виконаний у H1, не повторюється в H2. Для погодженого постійного заходу фактичний строк у звіті — 30 червня або 31 грудня. Майбутні рядки показують план. За відсутності погодженої версії звіт не приписує фактичну дату або причину невиконання.

Аналітична довідка показує підрахунки за станами й частку повністю виконаних заходів від усіх рядків. Посилання на проблемний захід відкриває потрібний період і погоджену ревізію, якщо вона є. [Контракт вибірки](workflow-contract.md#піврічний-звіт-і-аналітична-довідка)
