# Документація

Тут зберігаються матеріали командного рішення:

- формулювання обраного завдання та опис проблеми;
- архітектура, технологічний стек і структура даних;
- інструкції встановлення та запуску;
- сценарій демонстрації й результати перевірки;
- перелік учасників із GitHub-акаунтами з форми подання.

Це початкова заготовка. Документацію потрібно доповнити під час розробки.
