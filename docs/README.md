## Дані, які ще потрібно уточнити

- Точні GitHub-логіни всіх, хто комітить; підтвердження прийняття запрошень.

Наразі відомий акаунт власника репозиторію: [@Hulkovskyi](https://github.com/Hulkovskyi). Повний склад команди у публічній документації зазначають лише за згодою учасників; для форми подання потрібні логіни всіх, хто комітить.

## Як працюємо командою

- Усі частини рішення зберігаємо в одному репозиторії; основна гілка — `main`.
- Комітять лише учасники з акаунтів, зазначених у формі подання. Ментор консультує.
- Перед роботою отримуємо зміни через Pull, після кожного коміту робимо Push.
- Домовляємося про файли й завдання, щоб не редагувати те саме одночасно.
- Коміти робимо невеликими зі зрозумілим описом. Зміни з робочих гілок вчасно зливаємо в `main`.
- Локальний `.env` виключено через `.gitignore`; `.env.example` додаємо лише за потреби, без значень.
- Для розробки й демонстрації використовуємо вигадані або знеособлені дані. Секрети, реальні персональні дані та службові документи не публікуємо.
- Використання ШІ й власні рішення записуємо в [ai.md](ai.md) під час роботи.
