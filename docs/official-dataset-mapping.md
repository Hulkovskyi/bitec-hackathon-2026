# Синтетичні матеріали Завдання №2

[ZIP організаторів](https://hack.bitec.com.ua/wp-content/uploads/2026/11/zavdannia-2-syntetychnyi-nabir-63022726.zip) містить умовну програму на 2026–2027 роки. Для запуску демо використовується `dani/nabir.json`. CSV та XLSX містять ті самі 13 таблиць і слугують для незалежної звірки.

## Що використовує застосунок

| Матеріал | Використання |
| --- | --- |
| Паспорт, 3 розділи, 14 підрозділів, 19 синтетичних користувачів | Структура програми, імена джерела та доступ у локальному демо. Позначення 5 ролей зіставляються з ролями застосунку. |
| 14 ризиків і 39 вимірювань | Довідник ризиків, індикатори стану ризику й архівні сигнали. |
| 50 заходів і 3 перенесення строків | Реєстр зі зв'язками за розділом, підрозділом і ризиком. Архівні перенесення використовуються для RF6. |
| 50 результатів H1 і 41 запис про підтвердження | Архівний результат і звіт у трьох розділах. Записи підтверджень містять назви умовних документів, контрольні суми й довідкові посилання. |
| 169 подій журналу | Історія джерела в архівній картці заходу з датою, автором і полями зміни. Події архіву зберігаються окремо від журналу поточних дій користувачів. |
| Еталонний звіт і ключ навмисних кейсів | Звірка 50 рядків звіту, 29 сигналів і їхніх джерельних об’єктів. |

Словник `dictionary.md` описує формати полів, статуси, звіт і правила сигналів. `generate.py` входить до ZIP організаторів. Для перевірки й імпорту достатньо наданих файлів.

## Як повторити звірку

1. Запустіть звірку ZIP. Скрипт зіставляє CSV, XLSX і JSON та перевіряє наявність словника, генератора й ключа.

   ```bash
   python3 scripts/verify-official-materials.py "/шлях/до/архіву.zip"
   ```

2. Імпортуйте JSON у локальну SQLite за [README](../README.md#локальне-демо-на-офіційному-наборі-bitec). Параметр `--verify` звіряє звіт і архівний журнал через API. Додайте `--risk-key` для перевірки сигналів за ключем організаторів.
3. У браузері відкрийте **Звіти → 2026 · І півріччя**. Натисніть назву заходу й відкрийте **Архівний журнал дій** під його архівним результатом. Для перегляду потрібен дозвіл читати журнал у межах доступу до заходу.

`GET /api/measures/:id/official-audit` повертає `items`, `total`, `page`, `pageSize` і `available`. Доступ обмежений дозволом `audit.read` та доступом до архівного результату. `available=false` позначає імпорт без вихідного журналу. Події подано в локальному часі джерела.
