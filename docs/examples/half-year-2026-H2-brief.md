# Приклад аналітичної довідки

Синтетична програма DEMO-1, H2 2026, вибірка Координатора А. Дата зрізу 2026-11-19.

Повністю виконано 1 із 3 заходів.

| Стан | Кількість |
| --- | ---: |
| Виконано | 1 |
| Виконано частково | 0 |
| Не виконано | 0 |
| Строк виконання не настав | 2 |
| Результат не погоджено | 0 |

Потребує уваги F-QA. Захід погоджено, а фактичне значення 10 од. дорівнює базовому 10 од. за цілі 100 од. Це джерело сигналів недосягнення цілі та відсутності покращення.
